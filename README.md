# CheckInn Web — Official App Landing & Sales Platform

An Apple-keynote inspired landing and sales web application for **CheckInn App**, designed to pitch and showcase the paperless guest check-in revolution to hoteliers, resort operators, and homestay hosts.

## ✨ Highlights & Features

- **Apple iPhone Launch Aesthetic**: Titanium dark mode palette, ambient blue & violet backglow, frosted glass pill navbar (`backdrop-blur-2xl`), SF Pro/Plus Jakarta typography, and polished bento grids.
- **Animated CheckInn iPhone 16 Pro Screen**:
  - **Live AI ID/Passport Scanner**: Animated laser beam over document, MRZ detection, biometric bounding boxes, and instant OCR parsing.
  - **Digital Signature Canvas**: Glass touch signature capture with cryptographic verification.
  - **Front Desk Live Ledger**: Paperless check-ins counter, guest search, and instant room status.
- **Zero Paper Manifesto**:
  - Highlights the end of printers, toner cartridges, photocopies, and dusty registers.
  - **Interactive Hotel Savings Calculator**: Slide between 5 and 250 rooms to estimate annual paper reams, front desk hours, and dollar savings.
- **Interactive Check-In Sandbox**:
  - Try CheckInn in 15 seconds directly in the browser! Pick sample guests, trigger AI OCR extraction, draw a signature on an HTML5 canvas, and issue a digital room key.
- **App Store & Google Play Store Downloads**:
  - Official-style download badges for Apple App Store and Google Play.
  - Scan-to-download mobile QR code.
- **Account Deletion Portal (App Store & Google Play Compliant)**:
  - Fulfills Apple App Store Guideline 5.1.1(v) and Google Play Store User Data policies.
  - Step-by-step in-app guide and an online web request form with immediate ticket confirmation.
  - Data retention & statutory archival timeline breakdown.
- **Legal Compliance Suite**:
  - Dedicated **Terms & Conditions** for SaaS hospitality software.
  - Dedicated **Privacy Policy** addressing camera permissions, AES-256 encryption, and GDPR/CCPA data rights.
  - Direct URL hash routing (`#delete-account`, `#privacy`, `#terms`) for App Store submission URLs.

## 🚀 Quickstart

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
